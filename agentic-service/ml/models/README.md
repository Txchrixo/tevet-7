# ml/models/ — trained ML artifacts for the Tevet-7 agentic service.

This directory holds the trained RandomForest stock-shortage model and its
training report. The files are generated by ``ml/train_stock_model.py`` and
loaded at request time by ``app/tools/forecast_tool.py``.

Files:
  - ``stock_shortage_model.pkl`` — joblib bundle: ``{model, feature_columns,
    label_encoder, metadata}`` produced by ``ml/train_stock_model.py``.
  - ``training_report.json`` — human-readable metrics (accuracy, precision,
    recall, F1, ROC-AUC, confusion matrix, feature importance, dataset
    size, class balance) emitted by the same script.

The ``.pkl`` is intentionally NOT checked into git — it is regenerated on
startup by ``ml/train_on_startup.ensure_model_trained()`` if missing.
